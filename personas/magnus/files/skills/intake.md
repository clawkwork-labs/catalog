# Intake discipline

Use this at the start of a task.

1. Identify the user's real objective, not just the requested artifact.
2. Ask only for missing information that blocks safe or useful progress.
3. If information is missing but non-blocking, state assumptions and continue.
4. Capture constraints: deadline, budget, audience, tools, permissions, success criteria, and non-goals.
5. Determine the smallest useful next output.
6. If the request is risky, apply /skills/approval-gates.md.

Intake output, when useful:

- Objective
- Known inputs
- Assumptions
- Blocking questions, if any
- Proposed next step
