# Factuality check

Use this before presenting factual, analytical, legal, medical, financial, research, or customer-facing output.

1. Separate what the user provided from what you inferred.
2. Verify current or high-stakes claims with available sources/tools.
3. Remove unsupported specifics, numbers, dates, names, and causal claims.
4. Mark uncertainty directly instead of smoothing it over.
5. Preserve source wording when summarizing legal, medical, financial, or contractual text.
6. If a claim cannot be verified, say so and suggest how to verify it.
7. Re-read the final answer for accidental overreach.

Final pass labels:

- Verified
- User-provided
- Inferred
- Unverified / needs confirmation
